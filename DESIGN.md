# Venueflow Design System

## Direction

Operate-mode venue board: the customer sees a live, legible event roster with availability treated as operational information. The interface refuses generic marketplace cards in favor of a timetable-like event list and a clear ticket tray.

## Visual Language

- Deep ink surface with paper-white data panels and a single electric-blue action color.
- Condensed display typography is reserved for event names and availability; a neutral system sans carries interface controls and body copy.
- Rows, dividers, and tabular figures establish rhythm. Status changes use color plus text, never color alone.
- Buttons are decisive rectangular controls; rounded pills are limited to small statuses.

## Interaction and Motion

- Event rows retain their position as availability updates; changed availability briefly receives a contained highlight.
- The booking tray updates quantity and total without a modal.
- Reduced-motion users receive immediate state changes.

## Accessibility

- WCAG AA contrast minimums, visible keyboard focus, semantic tables/lists where applicable, labelled inputs, and responsive single-column fallback.
